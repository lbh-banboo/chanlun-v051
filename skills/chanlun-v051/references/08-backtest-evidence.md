# 08 · 回测证据与诚实的局限

> ⚠ **读法**：下列数字全部来自 2020-07—2026-09/10 的**历史模拟**，描述性，**不代表未来收益，不构成投资建议**。
> ⚠ **版本**：线段"永久卡死"缺陷修复前后的数字差异很大。**以本章标"修复后"的为准**；标"修复前"的只用于说明"缺陷改变了什么"，已作废，别再引用。

## 1. 先说最重要的三句话

1. **优势主要来自"挑票"，不是买点本身。** 全市场没挑过的候选 13,495 笔，逐笔平均 **−0.116R**（95% 区间 −0.17 到 −0.05）；人工挑出的关注池 403 笔是 **+0.62R**；随机抽 64 只的篮子年化中位 −0.7%～+1.1%，关注池年化排在 **98%—100% 分位**。关注池是事后挑出来的强势票，回测的漂亮数字有相当一部分是这个带来的。
2. **收益靠少数长趋势，胜率只有两成多。** 胜率约 23%—25%，中位每笔约 −1.06R；赢的单子平均拿半年，亏的两周左右止损；去掉最好 3 笔，关注池账户总收益从约 +58%（51 条路径中位）缩到约 +6%（修复前是 +54%→−20%，即"去掉最好 3 笔就变负"这一条修复后不再成立，但仍然很集中）。
3. **市场档位是最有把握的一条。** 不接档位：256 只年化 −5.2%、回撤 −40.1%；接上：年化 +7.9%、回撤 −27.0%（修复后）。50 次扰动里回撤变小的比例 100%。**用缠论买卖点，必须同时用档位控总仓位。**

## 5. 稳健性（关注池，修复后）

| 变体 | 年化 | 最大回撤 |
|---|---|---|
| 基准（滑点 10bp，延迟 0） | 7.5% | −15.4% |
| 成本压力（滑点 20bp） | 7.6% | −15.4% |
| **入场延迟 1 根（30 分钟）** | **5.5%** | −16.5% |
| 入场延迟 2 根（60 分钟） | 5.6% | −16.0% |
| 退出：X1 盘整即退 | 2.4% | −16.2% |
| 退出：X3a/b/c 日线破 MA5/10/20 | −0.6%/−1.7%/0.8% | −14.8%/−18.6%/−17.7% |
| 退出：旧 ATR 吊灯 | 6.3% | −15.3% |
| 单笔风险 0.50% / 0.75% / 1.00% | 5.9% / 7.5% / 7.1% | −12.9% / −15.4% / −19.6% |
| 档位：只上限 / 不接档位 | 8.9% / 6.8% | −20.1% / −29.9% |

- **X2 结构退出仍是最好的卖法**：盘整即退、日线均线破位都明显更差——这是"不用均线卖"的证据。
- **单笔风险从 0.75% 加到 1.0%，修复后反而略降、回撤加深**：仓位已被档位和簇上限卡住，加风险只是加大回撤。所以**不得为凑收益目标加大单笔风险、名额或放宽条件**。
- **执行延迟敏感**：晚 1 根年化 7.5%→5.5%。这是盘中扫描必须每 30 分钟查一次的原因，也是"信号延迟记录"要如实标出的原因。

**收益集中度**：账户收益由少数几只票贡献——去掉贡献最大的 2 只，年化 7.5%→1.7%；去掉前 3 只→0.5%；去掉前 5 只→−0.4%（前 5 只合计约占全部正盈利的 57%）。账层的个股贡献是路径依赖的（同一笔 +51.6R 的大单，因入场时账户已持有多只票，仓位被总上限卡到 1/3），**判断信号好坏要看候选层，不要看账户层个股贡献**。

## 8. 引擎无前视

截断重算（把数据截到任意时刻重算，已发出的信号必须完全一致）：672 组（30 分钟）、1,344 组（日线）、2,016 组本地引擎、修复后 48 组，全部 **0 差异**。同样的买点改用"事后才知道的结构极值"成交，R 被夸大约 2—9 倍（三买 0.95→6.13）——这就是软件图上"漂亮买点"的来源。

## 9. 退潮期（soft/hard）的科学性评估：证据不足，别当择时信号

关于"退潮期是否科学"的评估结论（**只是计划与评估，没跑新回测**）：

**站得住的**：①规则写得死、无前视（沪深300 收盘 < MA20 且全市场宽度 < 45%，两条同时成立；用前一交易日收盘档位）；②**降回撤有证据**（见第 4 节，50 次扰动 100% 回撤变小）；③留了出口（手册把 soft 定为待验证参数，累计 20 笔以上再评估是否长期保留，并配了强制撤退条款）。

**站不住的**：
1. 45%/55% 阈值只做过一次很粗的平移检验（±5pp），结论"方向不一致"；
2. 支撑 soft 的"八样本回测"**不独立**：8 个样本里 6 个是 2015 年的不同切片，独立年份只有 2015、2018、2024；
3. 系统自己的拆分回测在买点 C 上对 soft **不利**（比较"退潮一律不开"与 soft）；
4. **标签太碎，真正的独立样本很少**：2020-07-01—2026-10-08 共 1,520 个交易日，退潮期占 35.1% 却被切成 100 段，段长中位数 3 日，连续 ≥20 日的只有 3 段；档位共切换 277 次，平均 5.5 日一换；
5. "100% 扰动配对回撤变小"只证明对**信号噪声**稳健（在同一段历史上随机丢 10% 信号），不证明对"别的行情"稳健；且接档位的同时压低了平均仓位；
6. V5.x 的收益证据被污染、集中，且票池有幸存者偏差。

**结论**：只够把退潮期当成**"降低回撤的仓位刻度"**，不够当成"能提高收益的择时信号"，更不够证明 soft（退潮期仍开仓）比 hard（禁开）好。**建议不改现行规则**（实时回测期不得据新回测改规则）；若要改，开新版本、重计 3 个月。

**hard 触发的机械推算**（观察用）：触发线＝沪深300 的 0.85 × 126 个交易日前收盘；基准日每天往后滑，触发线随之变化。横盘情景下可能在若干交易日后触发，之后至少 63 个交易日退潮期禁开新仓。这是机械推算，不是预测。

## 10. 方法论纪律（回测怎么做才算数）

1. **预登记**：先写规则、参数、判据、第几次看数据，冻结（记 md5），再跑；看过结果再改参数就是新版本。
2. **三样必报**：同票**随机入场基线**、**没挑过的对照组**、**事先冻结的判据**——缺一不算"某类买点有效"。关注池上同票随机入场就有 +0.52R，买点本身只多出 0.05—0.30R，置信区间含 0。
3. **只在同一段历史上扰动**证明不了对别的行情稳健；**只有一个 6 年窗口**，2023、2025 两年占了大部分收益。
4. **复现关卡**：改引擎后复跑，先让"修复前引擎重跑旧流水线"逐笔复现旧结果，再看修复后。（实例：三道关卡全过——事件流 256/256 相同、三臂候选逐笔相同、账户结果最大差 2e-16。）
5. **写账户层预登记前，逐条对照手册原文参数**（见 [01](01-trading-rules.md) 第 9 节末的教训）。
6. **幸存者偏差**：全市场对照要并入退市股；今天的成分股池无法去偏，只作旁证。
7. 实时回测期内**不得**根据新回测改买卖规则（手册 10.1）。

## 11. 缠论 SOP 的验证结论（买点定义的来龙去脉）

R1—R9 九条修订的证据（修复前引擎上做的事件层验证，方向性结论，具体数字待重跑）：
- **盘整背驰候选不开仓**：关注池上显著差于随机入场（配对差 −1.49R，95% 区间 [−2.51, −0.60]），10 项检验里唯一显著的。
- **二买不设"不破一买"过滤**：4 个"引擎×票池"格子里 3 个"跌破一买"的不比"不破"的差；过滤会少掉 22%—40% 的二买信号；样本小，只能说"没有证据支持过滤"，不能说"跌破的更好"。
- **不用均线卖、不用盘整即退**：见第 5 节。
- **仓位公式写成"取小"，并写明哪个约束在起作用**：按净值 1% 风险＋10% 上限，86%—97% 的信号被单票上限压住；按 V5.x 参数（0.75%×档位倍率、主板 20%、创业板科创板 10%），风险预算算出的仓位中位约净值 6.7%，只有约 11% 被单票上限压住，**更常见的限制是档位总仓位**。
- **失效价不是成交价**：预估额外滑点 0.15—0.24R。
- **不与 V2.6 买点 C 叠加**：买点 C 是 250 日新高突破的右侧买点，缠论一买二买是低位结构，天然不重叠；叠加后只剩 1—18 笔，样本不足。
- ⚠ SOP 事件层验证与叠加检验的 S 引擎部分**同样受线段卡死缺陷影响，尚未按预登记重跑**；上述取舍的证据级别因此是"方向已见，数字待复核"。
