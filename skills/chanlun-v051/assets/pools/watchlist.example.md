# 关注池（示例，请替换成你自己的名单）

- 确认日期：**2026-01-05**（示例）
- 优先级：**本文件是股票池的唯一权威来源**。`v51_scan.py` / `pool_watch.py` / `pool_tool.py` 都解析本文件。
- **下游解析契约（改本文件前必读，改完跑 `python3 scripts/pool_tool.py check`）**：
  1. 名单表名称列**不得加粗**——会解析出 `**名称**`，静默污染全部下游标的名称。
  2. 名单表须在 `## 名单` 节内，且为**六列**（名称/代码/板块/加入日期/入池来源/状态）；行业分组行不带代码。
  3. 主题簇表须含「主题簇」「成员」两个表头；成员用顿号分隔，名称与名单表**完全一致**；**主题簇表之后不得再出现其它表格**（解析器会把后面的表格行当成簇行）。
  4. 冷却期说明与「最早 YYYY-MM-DD 可买回」必须写在名单表**对应标的的同一行**内；已过期的写「冷却期已解除」。
  5. 「加入日期」写 `YYYY-MM-DD`（当天收盘后入池）或 `YYYY-MM-DD HH:MM`（盘中入池）；日期里带「前」字（如「2025-06-01 前」）表示不设限，**只给实时回测起点之前就在池里的存量票用；起点之后新增的票不要用**（`pool_tool.py check` 会提示）。
- 入池 ≠ 可买：入池只是观察名单。能不能买只由 V5.1 的结构买点与八道闸门决定。

## 维护规则

- **清仓后自动转入**：持仓股清仓后转入本池，转入时同时登记：转入日期、清仓成交价与已实现盈亏、**卖出后冷却期（至少 3 个交易日，逐日列出，禁止写「冷却至 X」）**、申万板块（须取数，不得按印象填）、主题簇归属（申万三级相同 ≠ 同一主题簇）。
- **入池前置检查两道**：①代码 + 申万板块实际取数（取不到标「待取数」）；②**1.5a 资金可交易性**：收盘价 × 一手（科创板 200 股）≤ 单票上限，且收盘价 ≤ 价格天花板（`pool_tool.py ceilings`）。超限的可以入池跟踪，但状态列必须显式写「1.5a 闸门不通过」。
- **名称核对**：行情源对错字名会模糊匹配，返回的实体名可能与输入名不一致；新增时逐只比对，不一致先向使用者确认（`pool_tool.py add --entity-name`）。
- 板块列如需换口径，必须整列一次性替换，不得逐行混填。
